# 第十一课设计与证据（2026-10-19）

基于s10 e71518c。思想/实践order21/22，partOrder11。问题：已有程序结果后，报告模型请求失败；重跑整轮会重复副作用。三个职责为分类、等待计算、单模型请求恢复。独立包装s10的parent，不复制或修改唯一循环；s10公开入口按路径加载自身core以支持复用，API签名保持。

每逻辑请求最多4尝试，父会话共享20尝试/3秒计划等待；出站前扣数、睡眠前预留秒数，失败不返还。临时状态429/500/502/503/504/529或类型化连接/超时可尝试；401/403/400/413/未知停止。输出截断仅1024→2048一次、第二次停下，不保存部分响应或执行其中工具。无反应式裁剪、续写、换模型；第八课整理仍在原逻辑调用前。Retry-After有限非负秒数优先，日期/无效格式回退；超过预算停止，不缩短服务器要求。默认不真实睡眠；live父发送与等待真实，子/摘要仍固定。

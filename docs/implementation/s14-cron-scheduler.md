# 第十四课设计与证据（2026-10-19）

编辑卡：读者已理解后台收据和唯一循环；问题是“没有新输入时，谁在到点后产生工作”。可验证结果为每5分钟表、同分钟不重复、忙时队列保留、空闲串行交付、执行仍需许可。固定UTC+08:00、Python3.10+标准库/可选Anthropic1.13.0；不实现完整cron语法、持久化或停机补发，不复制参考所谓Claude内部源码。

依据：参考https://learn.shareai.run/zh/s14/（2026-10-19）提供时间表/触发/空闲交付思路；官方https://code.claude.com/docs/en/scheduled-tasks明确到点入队/轮次之间运行/本地时区，产品当前版本与参考的持久描述有差别，本站不宣称教学实现等于官方产品。Cronie官方man/crontab.5用于核对日/星期OR；仅采用明示子集。

实际设计：cron_matches/enqueue_due/dispatch_next，最多4表/8待交付/8最近结果；last_slot仅成功入队后更新，UTC分钟ID/回拨旧时刻跳过/不补发。RLock包状态短段，回调在锁外，finally结果与active释放同一临界段。非daemon可停调度线程不修改messages；消费者交付新问题给原run_loop。时间表仅会话，取消清未交付不终止active；失败记录不自动重跑。前课正式循环/提示/恢复/权限/Hook继续使用，不叠加s13异步进程、s12持久图或s08压缩。

实际入口输出1/0/1入队，busy保持2项，允许真实运行两次42；拒绝不运行。12标准库测试含Event门控真实生产线程可在轮次执行期间入队，第二消费者busy，取消、队列满后同分钟重试、单次表、时区/跨日/回拨、异常和KeyboardInterrupt释放，计数xx与拒绝无文件。18原样函数输入通过；SDK允许4请求（529一次）/拒绝3，进程一次/零，无在线模型。站点固定公开提交后另存快照/浏览器/部署证据。
